# Configuration reference

Configuration comes from three places:

1. **Platform settings.** Environment variables or CTFd config. Every
   `ARENA_*` environment variable is copied into the Flask config at plugin
   load (`config.import_environment`). A value already in `app.config` wins,
   and an empty value counts as unset.
2. **Per-event settings.** Stored on the event and edited in the admin UI or
   with `PATCH /api/v1/arena/admin/events/<id>`. They use a closed schema, so
   unknown keys are rejected.
3. **Runner settings.** Environment variables on the runner host only.

## 1. Platform: Arena keys

| Key | Default | Notes |
|---|---|---|
| `ARENA_ENABLED` | `true` | `false` loads only the CLI, so you can migrate before enabling. |
| `ARENA_SECRET_KEY` | falls back to `SECRET_KEY` | **Set it, with 32+ characters (enforced).** It derives the Fernet key for lab credentials and the certificate-verification HMAC. Back it up: encrypted lab credentials cannot be recovered without it. |
| `ARENA_FLAG_SECRET` | falls back to `SECRET_KEY` | HMAC key for per-entity Jeopardy flags and A&D flags. Changing it invalidates flags already issued. |
| `ARENA_PUBLIC_URL` | empty | Absolute base URL for links in certificates. |
| `ARENA_CERTIFICATES_ENABLED` | `false` | Certificates are optional. When this is false, none of the certificate routes are registered. |
| `ARENA_RUNNER_MODE` | `mock` | `mock` runs no containers; `remote` uses the runner service. |
| `ARENA_RUNNER_URL` | empty | `https://runner-host:8443`. `http://` is refused unless `ARENA_RUNNER_ALLOW_HTTP` is set (tests only). |
| `ARENA_RUNNER_KEY_ID` / `ARENA_RUNNER_SECRET` | empty | HMAC credentials that match the runner's `ARENA_RUNNER_KEYS`. The secret must be at least 32 characters. |
| `ARENA_RUNNER_CA` | system trust | Path to the CA bundle that verifies the runner's certificate. |
| `ARENA_RUNNER_ALLOW_HTTP` | unset | Test-only escape hatch. Never set it in production. |
| `ARENA_MAX_INSTANCES_PER_EVENT` | `200` | Platform-side instance quota per event. |
| `ARENA_LAB_ALLOWED_PRIVATE_HOSTS` | empty | Comma-separated hostnames that external lab providers may use even when they resolve to private addresses. `http://` is also allowed for them. |
| `ARENA_SCHEMA_CHECK_TTL` | `30` | Seconds to cache a positive "schema is current" result. |
| `ARENA_REDIS_TIMEOUT` | `0.25` | Socket timeout in seconds for Arena's own Redis client (locks, buffers). |
| `ARENA_REDIS_BREAKER_SECONDS` | `5` | How long Arena skips Redis after a failure (the circuit breaker). |
| `ARENA_ACTIVITY_QUEUE_CAP` | `100000` | Maximum length of the Redis activity buffer. Oldest entries are dropped beyond it. |
| `ARENA_ACTIVITY_RETENTION_DAYS` | `180` | Retention for participant activity records. |
| `ARENA_AUDIT_RETENTION_DAYS` | `730` | Retention for admin and audit records. |
| `ARENA_JOBS_MAX_QUEUED` | `1000` | Back-pressure: enqueue raises `QueueFull` once this many jobs **of the same kind** are queued. |

### Native CTFd keys that matter for Arena deployments

| Key | Profile B/C value | Why |
|---|---|---|
| `SECRET_KEY` | generated | Must be identical on all web replicas and workers. |
| `DATABASE_URL` | `mysql+pymysql://…@db/ctfd` | MariaDB 10.11. SQLite is for development only. |
| `REDIS_URL` | `redis://:pw@cache:6379/0` | Required for multiple replicas: shared sessions and cache. |
| `REVERSE_PROXY` | `true` | Trusts one proxy hop; nginx overwrites `X-Forwarded-For`. |
| `WORKERS` | 2 (B), 4 per replica (C) | gunicorn gevent workers. A login costs about 280 ms of CPU (bcrypt, see the performance report). |
| `GUNICORN_CMD_ARGS` | `--keep-alive 75` | Must stay above nginx's upstream `keepalive_timeout` (30 s). |
| `RATELIMIT_LOGIN` / `RATELIMIT_REGISTER` | `10,5` (default) | Per IP. Raise them for venues where everyone shares one NAT address. |

## 2. Deployment (`deploy/.env`)

| Key | Notes |
|---|---|
| `ARENA_DOMAIN` | nginx `server_name` and the certificate name. |
| `MARIADB_ROOT_PASSWORD`, `MARIADB_PASSWORD`, `REDIS_PASSWORD` | Generated by `gen-secrets.sh`. Compose refuses to start without them. |
| `ARENA_RATELIMIT_EXEMPT_CIDR` | One trusted range (for example a venue NAT) that nginx's per-IP limits skip. Empty means none. |
| `ARENA_IMAGE` | Image tag (default `arena-platform:local`). |
| `ARENA_COMPOSE_FILES`, `ARENA_ENV_FILE`, `ARENA_DEPLOY_MODE` | Used by the scripts in `deploy/scripts/` (see `lib.sh`). |

## 3. Per-event settings

| Key | Type | Default | Range / choices |
|---|---|---|---|
| `require_verified_email` | bool | false | |
| `allowed_email_domains` | list of domains | [] | Empty means any domain. |
| `invite_only` | bool | false | Registration needs an invite code. |
| `lock_teams_after_start` | bool | false | |
| `default_team_visibility` | choice | public | public, private |
| `max_attempts_default` | int | 0 | 0–1000 (0 = unlimited) |
| `submissions_per_minute` | int | 10 | 1–120. Incorrect submissions per entity, enforced in the database. |
| `per_entity_flags` | bool | false | HMAC-derived unique flag per team or user. |
| `individual_scoring` | bool | false | |
| `first_blood_bonus` | int | 0 | 0–100000 |
| `scoreboard_visibility` | choice | public | public, participants, admins |
| `scoreboard_refresh_seconds` | int | 15 | 5–300. Clients poll at this rate. |
| `show_solve_counts` | bool | true | |
| `ad_round_seconds` | int | 120 | 30–3600 |
| `ad_flag_lifetime_rounds` | int | 5 | 1–50 |
| `ad_warmup_rounds` | int | 0 | 0–20 |
| `ad_flag_submissions_per_minute` | int | 60 | 1–1000 |
| `max_instances_per_entity` | int | 2 | 0–20 |
| `instance_ttl_minutes` | int | 60 | 5–1440 |

Scoring weights and the tie-break order are **versioned** scoring configs,
not settings. Change them with
`POST /api/v1/arena/admin/events/<id>/scoring/configs`; before and after
standings are snapshotted.

## 4. Runner host (`runner/.env`)

| Key | Default | Notes |
|---|---|---|
| `ARENA_RUNNER_KEYS` | — (required) | `key_id:secret[,key_id:secret]`. Each secret must be at least 32 characters. Several keys allow rotation. |
| `ARENA_RUNNER_BACKEND` | `mock` | `docker` for real containers. |
| `ARENA_RUNNER_ALLOWED_IMAGES` | empty | Comma-separated `repo@sha256:<digest>`. Only digest-pinned references are accepted. |
| `ARENA_RUNNER_PUBLIC_HOST` | `127.0.0.1` | Host name or IP that participants connect to. |
| `ARENA_RUNNER_BIND_IP` | `0.0.0.0` | Network interface that challenge ports bind to. Set it to the public NIC. |
| `ARENA_RUNNER_PORT_RANGE` | `30000-30999` | |
| `ARENA_RUNNER_MAX_INSTANCES` | `200` | |
| `ARENA_RUNNER_MAX_TTL` | `14400` | Seconds. Requests above this are capped. |
| `ARENA_RUNNER_DB` | `/var/lib/arena-runner/state.db` | SQLite state (instances and nonces). |
| `ARENA_RUNNER_DOCKER_RUNTIME` | empty | For example `runsc` (gVisor), if installed. |
| `GUNICORN_CMD_ARGS` | set by `runner.yml` | Certificate and key for the TLS control API. |
